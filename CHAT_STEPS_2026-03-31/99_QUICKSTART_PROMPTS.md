# Quickstart Prompts For New Chats

Use one prompt at a time. Replace STEP_FILE with the exact step markdown file path.

## Generic Step Prompt

Continue implementation using instructions in STEP_FILE.
Keep scope limited to that file's in-scope list.
Do not expand into later steps.
Run the listed verification tasks.
At the end, report completion against acceptance criteria and list any blockers.
